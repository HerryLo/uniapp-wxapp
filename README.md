# 宝宝记录与工具箱

基于 uni-app + Vue 3 + Vite 的本地优先小程序「垣计算」：宝宝记录 + 日常计算工具。数据与计算都在本机完成，无后端依赖。

## 功能

### 宝宝（Tab）

- 宝宝资料：头像、昵称、出生日期、性别与月龄，点首页头像可直接更换
- 侧边栏：首页、喝奶、睡眠、排便、辅食、补剂、用药、疫苗、生长、手记、妈妈、旅行；可收起为悬浮按钮并拖动位置
- 日常记录：喝奶、睡眠、排便、辅食、用药、补剂，首页汇总今日喝奶次数、睡眠时长与排便次数
- 奶量趋势：最近 7 天列表，有奶量记录超过 3 天时显示折线图
- 生长曲线：身高体重记录与 canvas 折线图
- 疫苗参考：一类 / 二类清单、已接种标记与日期、自定义疫苗，二类可单项或批量标记「暂不接种」
- 成长手记、妈妈记录、旅行记录
- 数据管理：JSON 导出 / 恢复 / 清空，恢复前自动备份当前数据

### 我的（Tab）

- 本地模式说明与数据同步占位（不发起网络请求）
- 工具箱入口：增值税、单位换算、文本处理、进制转换
- 宝宝资料、数据管理（导出 / 恢复 / 清空）、关于与免责声明

### 工具

- 增值税计算：含税 / 不含税双向换算，支持自定义税率
- 单位换算：长度、重量、温度、存储、面积
- 文本处理：按行去重、大小写转换
- 进制转换：2–36 进制，支持负数与超大整数

右下角悬浮按钮打开「全部工具」抽屉，默认展示增值税。

## 运行

```bash
npm install

npm run dev:mp-weixin   # 小程序开发
npm run dev:h5          # H5 调试（仅用于本地查看）
npm test                # 单元测试
npx vitest run tests/baby-records.test.js   # 单个测试文件
```

也可以用 `yarn` 执行同样的脚本。

微信小程序：用微信开发者工具导入 `dist/dev/mp-weixin`；发布前把 `src/manifest.json` 里的 appid 换成自己的。

## 构建

```bash
npm run build:mp-weixin
npm run build:h5
```

## 目录结构

- `src/pages/baby/index.vue`：宝宝首页（今日记录、下一条疫苗、最近生长）
- `src/pages/mine/index.vue`：我的页
- `src/pages/tools/index.vue`：工具页与「全部工具」抽屉
- `src/pages/about/about.vue`：关于、免责声明与隐私说明
- `src/package-baby/`：宝宝分包（日常记录、生长、疫苗、手记、妈妈、旅行、宝宝资料、数据管理）
  - `records/*.vue`：六类记录页，复用 `components/records/RecordPage.vue`
  - `components/`：记录页外壳、表单、列表与 canvas 折线图
  - `composables/useDayRecords.js`：单日记录的状态与增删逻辑
  - `utils/`：备份恢复、手记、妈妈记录、旅行记录与同步快照封装
- `src/components/baby/`：宝宝页外壳（含侧边栏）与通用组件
- `src/components/tools/`：四个工具面板
- `src/data/`：疫苗参考清单
- `src/utils/baby/`：宝宝模块纯逻辑、存储 key 与本地存储封装
- `src/utils/`：工具计算逻辑与剪贴板等通用工具
- `tests/`：Vitest 单元测试
- `docs/superpowers/`：设计文档与实施计划
- `scripts/gen-tab-icons.cjs`：生成 tabBar 图标

## 说明

- 数据只保存在本机，不登录、不上传、不申请定位权限；清理缓存或卸载小程序会丢失数据，请定期在「我的 - 数据管理」导出备份。
- 宝宝头像以压缩后的图片数据保存在本机，随备份一起迁移。
- 「我的」页的数据同步目前只是占位入口，不会发起网络请求。
- 版本更新：小程序冷启动时自动检查新版本，新版本下载完成后弹窗提示并强制重启；使用中切后台再返回不会触发检查，重新打开小程序即可。
- 宝宝记录与疫苗参考仅用于家庭记录，不构成医疗建议、诊断或接种推荐；具体问题请咨询医生，疫苗安排以当地接种门诊为准。
- 广告出现在工具页、宝宝首页与喝奶记录页。
- 旧待办数据 key `tools.todos.v1` 已不再使用，但不会被自动删除。
