# 宝宝记录与工具箱

基于 uni-app + Vue 3 + Vite 的本地优先小程序：宝宝记录 + 日常计算工具。所有数据与计算均在本机完成，无后端依赖。

## 功能

### 宝宝（Tab）

- 宝宝资料：头像、昵称、出生日期、性别与月龄
- 侧边栏导航：首页、喝奶、睡眠、排便、辅食、用药、补剂、疫苗、生长、手记、妈妈、旅行；可收起为悬浮按钮，拖动调整位置（设置不在侧栏，可从「我的」或宝宝首页资料卡进入）
- 日常记录：喝奶、睡眠、排便、辅食、用药、补剂，首页汇总今日喝奶次数、睡眠时长与排便次数
- 奶量趋势：最近 7 天奶量列表，有奶量记录超过 3 天时显示折线图
- 生长曲线：身高体重记录与 canvas 折线图
- 疫苗参考：一类 / 二类参考清单、已接种标记与接种日期、自定义疫苗；二类疫苗可单项或批量标记「暂不接种」
- 成长手记：里程碑、每日心情、育儿心得
- 妈妈记录：每日心情、睡眠时长、身体状态与备注
- 旅行记录：出行日期、地点与备注
- 数据管理：JSON 导出 / 恢复 / 清空，恢复前自动备份当前数据

### 我的（Tab）

- 本地模式：不登录，宝宝资料与记录仅保存在本机
- 数据同步：目前为占位入口，不会发起网络请求
- 工具箱入口：增值税、单位换算、文本处理、进制转换
- 数据与设置：宝宝资料、导出恢复与清理；另有关于与免责声明

### 工具（从「我的」进入）

- 增值税计算：含税/不含税双向换算，支持常用税率与自定义税率
- 单位换算：长度、重量、温度、存储、面积
- 文本处理：按行去重、大小写转换
- 进制转换：2–36 进制，支持负数与超大整数

工具页右下角的悬浮按钮打开「全部工具」抽屉，默认展示增值税。

## 运行

```bash
npm install

# 微信小程序开发
npm run dev:mp-weixin

# H5 开发（仅用于本地调试）
npm run dev:h5

# 单元测试
npm test

# 只跑单个测试文件
npx vitest run tests/baby-records.test.js
```

也可以使用 `yarn` 执行同样的脚本。

微信小程序：使用微信开发者工具导入 `dist/dev/mp-weixin`。发布前请先将 `src/manifest.json` 中的 appid 改为自己的小程序 appid。

## 构建

```bash
npm run build:mp-weixin
npm run build:h5
```

## 目录结构

- `src/pages/baby/index.vue`：宝宝首页（今日记录、下一条疫苗、最近生长）
- `src/pages/mine/index.vue`：我的页（本地模式、同步占位、工具箱入口、数据与设置）
- `src/pages/tools/index.vue`：工具页与「全部工具」抽屉（从「我的」进入）
- `src/pages/about/about.vue`：关于、免责声明与隐私说明
- `src/package-baby/`：宝宝分包页面（日常记录、生长、疫苗、手记、妈妈、旅行、设置）
  - `records/*.vue`：喝奶 / 睡眠 / 排便 / 辅食 / 用药 / 补剂记录页，复用 `components/records/RecordPage.vue`
  - `components/`：记录页外壳、记录表单、列表与 canvas 折线图
  - `composables/useDayRecords.js`：单日记录的状态与增删逻辑
  - `utils/`：备份恢复、成长手记、妈妈记录、旅行记录与同步快照封装
- `src/components/baby/*`：宝宝页外壳（含侧边栏）与通用组件
- `src/components/tools/*`：增值税、单位、文本、进制面板
- `src/data/*`：疫苗参考清单数据
- `src/utils/baby/*`：宝宝模块纯逻辑、存储 key 与本地存储封装
- `src/utils/*`：工具箱计算逻辑与剪贴板等通用工具
- `tests/*.test.js`：Vitest 单元测试（纯逻辑，stub 全局 `uni`）
- `docs/superpowers/`：需求设计与实施计划
- `scripts/gen-tab-icons.cjs`：生成 tabBar 图标脚本

## 说明

- 宝宝资料与记录只保存在本机，不登录、不上云、不申请定位权限。
- 宝宝头像以压缩后的图片数据保存在本机，并随导出备份一起迁移。
- 「我的」页的数据同步目前只是占位，不会发起网络请求。
- 清理小程序缓存或卸载小程序会丢失本机数据，请定期在「数据与设置」中导出备份。
- 宝宝记录与疫苗参考仅用于家庭记录，不构成医疗建议、诊断或接种推荐；具体健康问题请咨询医生，疫苗安排以当地接种门诊为准。
- 广告出现在工具页、宝宝首页与喝奶记录页。
- 旧待办数据 key `tools.todos.v1` 不再使用，但不会被自动删除。
