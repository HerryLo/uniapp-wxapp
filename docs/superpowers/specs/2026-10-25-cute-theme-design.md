# 奶油糖果风可爱化设计

日期：2026-10-25
范围：全部页面与共享组件

## 目标

在现有粉色主题基础上，用奶油糖果风统一提升可爱度：更圆润的卡片、柔和阴影、胶囊按钮、粉/薄荷/柠檬点缀、少量 emoji 和轻微按压反馈。不改布局结构、业务逻辑和数据。

## 设计原则

- 可爱但不影响可读性：表单、计算结果、数字区域保持清晰克制。
- 只用 CSS 和 emoji，不引入外部图片、字体或依赖。
- 轻微动效只放在可点击元素上，不做循环动画。
- 所有页面共享同一套圆角、阴影、按钮和标签规范。

## 色彩与形状

### 颜色

沿用现有变量，并补充奶油糖果色：

```css
--bg: #FFF9F5;
--surface: #FFFFFF;
--primary: #FF8FA3;
--primary-strong: #E86F87;
--primary-soft: #FFE4E1;
--accent: #B5E4CA;      /* 薄荷 */
--accent-warm: #FFD93D; /* 柠檬 */
--peach: #FFB6C1;       /* 蜜桃 */
--cream: #FFFDFC;
--text: #4A4A4A;
--text-secondary: #888888;
--border: #FFE4E1;
```

### 形状

- 卡片圆角：48rpx；阴影改为 `0 10rpx 30rpx rgba(255, 143, 163, 0.14)`。
- 按钮、标签、分享按钮、chips：胶囊形（999rpx）。
- 输入框、选择器、textarea：圆角 28rpx，背景 `--cream`。
- 结果区、空状态、提示框：奶油底 + 24–32rpx 圆角。

### 微交互

- `.btn:active`、`.chip:active`、`.sidebar-item:active`、`.tool-cell:active`：
  `transform: scale(0.97); opacity: 0.9;`
- 过渡：`transition: transform 0.12s ease, opacity 0.12s ease;`
- 不对卡片和列表整块做缩放，避免误触感。

## 全局样式（`src/App.vue`）

- `.card`：48rpx 圆角、柔和阴影、1rpx 半透明边框。
- `.btn`：胶囊形；`.btn-primary` 使用粉色渐变（`#FF9FB1` → `#E86F87`）和柔和阴影；`.btn-ghost` 保持白底粉边。
- `.input`、`.textarea`、`.picker-field`：28rpx 圆角、`--cream` 背景；输入时边框变 `--primary`。
- `.chip`：默认浅粉底、胶囊；`.chip.active` 使用粉色渐变或深粉字。
- `.result-box`：奶油底、32rpx 圆角、细边框。
- `.empty-tip`：居中、辅助色、行高 1.7。
- `page`：保持奶油底；增加极淡的粉色径向渐变作为背景氛围（仅 CSS，不增加图片）。

## 边界与兼容

- 所有 emoji 使用系统字体，不需要图片资源。
- 颜色对比度保持现有文字色，不把正文放到深色或高饱和背景上。
- 输入框、表格、图表的功能和尺寸不变；仅调整圆角、背景和阴影。
- 不修改任何数据读写、备份、分享、广告和侧栏逻辑。
- H5 与微信小程序共用同一套样式。

## 不在范围

- 不引入 UI 组件库、图标库或外部字体。
- 不改页面结构、信息层级、业务逻辑。
- 不做循环动画、粒子效果或复杂手绘插画。
