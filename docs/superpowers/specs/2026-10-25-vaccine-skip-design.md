# 疫苗提示与二类跳过设计

日期：2026-10-25

## 目标

- 首页「下一条疫苗参考」只提示一类疫苗，不再推送二类自费疫苗
- 二类疫苗可以标记「暂不接种」，并可恢复
- 一类疫苗保持基础免疫提示，不提供跳过
- 数据结构向后兼容，不影响已有备份

## 数据模型

疫苗记录新增可选字段：

```js
{
  id, name, month, type, done, date, builtin,
  skipped: boolean
}
```

- 旧数据没有 `skipped` 时按 `false` 处理
- `skipped: true` 时同时保证 `done: false`、`date: ''`
- 标记为已接种时自动清除 `skipped`
- 跳过状态随疫苗列表保存，并进入导出/恢复

## 逻辑接口

### `vaccines.js`

- `setVaccineSkipped(list, id, skipped)`：
  - 跳过时清除已接种状态和日期
  - 恢复时只清除 `skipped`
- `vaccineStatus(vaccine, totalMonths)`：
  - `skipped` 优先返回 `{ key: 'skipped', label: '暂不接种' }`
- `nextVaccine(list, totalMonths, options)`：
  - 新增 `options.type` 过滤
  - 自动排除 `done` 和 `skipped`
  - 首页调用 `nextVaccine(list, months, { type: '一类' })`
- `setVaccineDone`：
  - 标记已接种时清除 `skipped`
- 内置和自定义疫苗初始化 `skipped: false`

## 页面

### 宝宝首页

- 卡片标题改为「💉 下一条一类疫苗参考」
- 只查询一类疫苗
- 一类全部完成时显示「一类疫苗已按参考程序完成」
- 未填写出生日期时保持现有提示

### 疫苗参考页

- 二类且未接种的条目在名称下方显示「暂不接种」胶囊按钮
- 点击后二次确认：
  - 标题「暂不接种」
  - 内容「确定将「X」标记为暂不接种吗？之后可恢复参考。」
- 已跳过的条目状态显示「暂不接种」，并显示「恢复参考」按钮
- 恢复后重新参与排序和状态显示
- 二类分组提供批量按钮：全部暂不接种 / 全部恢复参考
  - 只处理未接种的二类项，已接种项不受影响
  - 所有未接种二类项都已跳过时，按钮切换为「全部恢复参考」
- 一类条目不显示跳过按钮
- 复选框仍可勾选；实际接种后点击勾选会自动清除跳过状态

## 合规文案

- 使用「暂不接种」「恢复参考」，不使用「拒绝」「不建议」等措辞
- 二类说明保留「自费自愿，请咨询接种门诊」
- 不提供医疗建议，只记录用户选择

## 测试

- 跳过/恢复、状态计算、首页一类过滤、已接种清除跳过
- 旧数据无 `skipped`、备份包含跳过状态
- 现有测试和双端构建保持通过
