# 疫苗参考页表格化设计

日期：2026-10-24
范围：`src/package-baby/health/index.vue`

## 目标

将疫苗参考页的一类、二类疫苗列表改为可横向滑动的表格，便于按列对比参考月龄、状态和接种日期，同时保留现有全部交互。

## 现状

页面按一类 / 二类分组，每组是一个卡片，内部逐条展示「勾选 + 名称 + 参考月龄 + 状态」，已接种时展开日期行，自定义项可删除。逻辑来自 `src/utils/baby/vaccines.js`，本次不改动。

## 设计

### 布局

- 使用纯 `view` 单元格 + flex 布局，外层一个 `scroll-view scroll-x` 横向滚动。
- 一类、二类两张表放在同一个滚动容器内，列宽一致、滚动位置统一。
- 页面本身仍由原生纵向滚动处理，不嵌套纵向 `scroll-view`。
- 表格上方增加一行提示：「左右滑动查看完整表格」。

### 列定义

| 列 | 宽度 | 内容 |
|---|---|---|
| 勾选 | 72rpx | 复选框，点击切换已接种 |
| 疫苗名称 | 300rpx | 名称；二类显示「自费自愿」标签；超过参考月龄时下方显示「请咨询接种门诊」小字 |
| 参考月龄 | 140rpx | `formatMonthAge(item.month)` |
| 状态 | 160rpx | 已接种 / 待接种 / 已超过参考月龄 / 未接种，沿用现有颜色 |
| 接种日期 | 200rpx | 已接种时显示日期选择器（点击修改），未接种显示「—」 |
| 操作 | 100rpx | 自定义项显示「删除」，内置项显示「—」 |

总宽约 972rpx，超出屏幕内容宽度，产生横向滑动。

### 分组与合规文案

- 每组顶部保留「一类疫苗」「二类疫苗」标题。
- 二类保留「自费自愿」标签与「二类疫苗为自费自愿接种，请咨询接种门诊。」说明。
- 免责声明、参考来源卡片、自定义疫苗弹层保持不变。

### 交互

- 点击勾选列：`toggle(item)`。
- 已接种时点击日期：打开日期选择器，`changeDate(item, date)`。
- 点击「删除」：二次确认后 `removeCustom(item)`；阻止事件冒泡，避免触发行点击。
- 所有数据读写继续走 `loadVaccines` / `saveVaccines` 等现有函数，不改存储结构。

### 样式

- 表头背景 `#FFF1F3`，文字 `var(--text-secondary)`，字号 24rpx。
- 行间使用 `var(--border)` 分隔线，单元格垂直居中，名称列允许换行。
- 保持粉色主题变量与卡片圆角，不引入新依赖。

## 边界与错误处理

- 无出生日期时，月龄显示「未设置」，状态显示「未接种」，与现状一致。
- 疫苗列表为空时表格只显示表头，不报错。
- 横向滑动不影响勾选、日期选择和删除点击。
