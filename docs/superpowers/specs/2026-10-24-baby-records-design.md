# 宝宝记录与工具箱双 Tab 改造设计

- 日期：2026-10-24
- 状态：已确认
- 定位：工具类小程序，本地优先
- 前置设计：`2026-10-23-tool-miniapp-design.md`、`2026-10-24-tools-nav-redesign-design.md`

## 1. 背景与目标

当前小程序只有「工具 / 待办」两个 tab。待办与工具、宝宝记录两类核心场景关联较弱，移除后结构更清晰。

本次改造目标：

1. 移除待办功能，小程序保留两个 tab：**工具**、**宝宝**。
2. 新增「宝宝记录」模块，把原网页《宝宝成长记录》中的记录能力迁入小程序。
3. 宝宝模块定位为**记录工具**，不提供诊断、剂量、治疗等医疗建议。
4. 数据默认只保存在本机，不登录、不上云；位置打卡与云端同步延后。
5. 采用「宝宝首页（主包）+ 分包子页面」的结构，控制主包体积。

## 2. 定位与边界

### 2.1 产品定位

- 对外描述：**本地优先的宝宝记录工具 + 日常计算工具箱**。
- 宝宝模块只做：记录、统计、参考清单、数据导出。
- 不做：诊断、治疗建议、处方、剂量推荐、生长发育评估结论。

### 2.2 内容约束

- 删除原网页中硬编码的处方药名称和剂量（奥美拉唑、铝碳酸镁等）。
- 补剂、用药本期不进入 MVP；二期如加入，只允许用户自定义名称，不预置剂量。
- 疫苗清单作为**可编辑参考清单**，状态使用「已接种 / 待接种 / 已超过参考月龄」，不使用「逾期」等医疗判断措辞。
- 预置一类和二类疫苗；二类必须标注「自费自愿」并提示「请咨询接种门诊」，不使用「推荐」等措辞。
- 生长曲线只展示用户记录的数据，不做「偏矮 / 偏胖」等结论。
- 所有健康相关页面展示免责声明，并在关于页统一说明。

### 2.3 数据与隐私

- MVP 不采集、不上传数据，全部写入 `uni.setStorageSync`。
- 不申请定位权限；旅行模块本期不做。
- 提供数据导出与恢复，用户自行决定备份文件去向。
- 设置页明确提示：清理小程序缓存或卸载会丢失本机数据。

## 3. 信息架构

### 3.1 导航

tabBar 仅保留两项：

| tab | 页面 | 说明 |
|---|---|---|
| 工具 | `pages/tools/index` | 现有增值税、单位换算、文本处理、进制转换 |
| 宝宝 | `pages/baby/index` | 宝宝首页（主包 tab 页） |

关于页 `pages/about/about` 保留，继续从工具页和宝宝设置页进入。

### 3.2 页面结构

主包：

- `pages/tools/index`：现有工具页，移除待办角标逻辑。
- `pages/baby/index`：宝宝首页。
- `pages/about/about`：关于与免责声明，更新功能列表。

分包 `package-baby`：

| 页面 | 路径 | 内容 |
|---|---|---|
| 日常记录 | `package-baby/records/index` | 喝奶、睡眠、排便的增删与今日统计 |
| 生长曲线 | `package-baby/growth/index` | 身高体重记录、折线图、历史 |
| 疫苗参考 | `package-baby/health/index` | 一类疫苗参考清单、已接种标记、自定义疫苗 |
| 成长手记 | `package-baby/journal/index` | 里程碑、参考里程碑、每日心情、育儿心得 |
| 数据与设置 | `package-baby/settings/index` | 宝宝资料、导出/恢复、清空数据、关于入口 |

### 3.3 宝宝首页

从上到下：

1. 宝宝资料卡：昵称、月龄、性别；未设置出生日期时显示「去设置」。
2. 快捷记录：喝奶、睡眠、排便三个按钮，跳转 `package-baby/records/index?type=milk|sleep|diaper` 并自动打开对应表单。
3. 今日统计：喝奶次数、睡眠小时、排便次数。
4. 参考疫苗卡：显示下一条未完成的疫苗；空状态显示「暂无待接种参考」。
5. 生长摘要：最近一次身高体重；无记录时显示引导。
6. 功能入口：生长曲线、疫苗参考、成长手记、数据与设置。
7. 底部广告位。

## 4. MVP 功能

### 4.1 宝宝资料

- 字段：昵称（默认「宝宝」）、出生日期、性别（男宝/女宝）。
- 校验：出生日期不能晚于今天；昵称最长 20 字。
- 月龄按月计算，忽略日差；首页显示「X 岁 Y 个月」或「X 个月」。

### 4.2 日常记录

喝奶：

- 时间（日期 + 时间，默认当前）。
- 类型：母乳 / 配方奶 / 混合。
- 奶量（ml）：可选，非负整数。

睡眠：

- 开始时间、结束时间均为日期 + 时间。
- 校验：结束时间必须晚于开始时间。
- 统计时只累加已完成记录；跨天记录计入开始日期。

排便：

- 时间（日期 + 时间，默认当前）。
- 类型：大便 / 小便 / 都有。
- 颜色：正常 / 绿色 / 黑色 / 白色 / 带血。

列表与统计：

- 今日记录按时间倒序展示，支持删除（二次确认）。
- 今日统计：喝奶次数、睡眠小时（保留 1 位小数）、排便次数。
- 空状态：「今天还没有记录」。

### 4.3 生长曲线

- 添加记录：日期、身高（cm）、体重（kg）。
- 同一日期只保留一条记录，再次添加视为更新。
- 校验：身高 20–200 cm，体重 0.5–100 kg。
- 展示身高、体重两张折线图；少于 1 条数据时显示「暂无数据」。
- 历史记录按日期倒序，支持删除。

### 4.4 疫苗参考

- 首次进入时用内置「一类疫苗参考清单」初始化，之后以本地数据为准。
- 字段：名称、参考月龄、类型（一类 / 二类）、是否已接种、接种日期。
- 列表按「一类」「二类」分组，组内按参考月龄排序；二类项显示「自费自愿」标签和「请咨询接种门诊」提示。
- 状态：
  - 已接种：显示接种日期。
  - 待接种：当前月龄 ≤ 参考月龄。
  - 已超过参考月龄：当前月龄 > 参考月龄，附「请咨询接种门诊」提示。
- 勾选已接种时默认填入今天，可修改日期；取消勾选时清空日期。
- 支持添加自定义疫苗（名称、类型、参考月龄可留空）；自定义疫苗可删除，内置参考项不可删除。
- 自定义疫苗未填参考月龄时，只显示「未接种 / 已接种」，不计算「已超过参考月龄」。
- 参考数据在 `src/data/vaccinePlan.js` 中收录一类与二类，并标注来源与整理日期。
- 页面顶部固定免责声明：参考清单不构成医疗建议，以当地接种门诊安排为准。
- 本页不展示广告。

### 4.5 成长手记

里程碑：

- 添加：日期、标题、备注。
- 时间线按日期倒序，支持删除。
- 参考里程碑作为折叠参考内容，标注「参考，不构成发育评估」。

心情：

- 每日一个心情：开心 / 平静 / 烦躁 / 困倦 / 兴奋，使用 emoji 展示。
- 同一天重复选择覆盖。

育儿心得：

- 文本记录，按日期倒序展示，支持删除。

### 4.6 数据与设置

- 宝宝资料编辑。
- 导出数据。
- 恢复数据。
- 清空宝宝数据（二次确认，保留工具相关数据）。
- 关于与免责声明入口。

## 5. 数据模型

### 5.1 存储 key

| key | 内容 |
|---|---|
| `baby.profile.v1` | 宝宝资料对象 |
| `baby.records.v1.YYYY-MM` | 按月存放的日常记录 |
| `baby.growth.v1` | 生长记录数组 |
| `baby.vaccines.v1` | 疫苗记录数组 |
| `baby.milestones.v1` | 里程碑数组 |
| `baby.moods.v1` | 日期到心情的映射 |
| `baby.notes.v1` | 育儿心得数组 |
| `baby.meta.v1` | `{ schemaVersion: 1 }` |
| `baby.backup.v1` | 最近一次导入前的数据备份 |

日常记录按月拆 key，避免单 key 触达 1MB 上限。旧待办数据 key `tools.todos.v1` 不做自动删除。

### 5.2 结构

```js
// baby.profile.v1
{ name: '宝宝', birthDate: 'YYYY-MM-DD', gender: 'boy' | 'girl', createdAt, updatedAt }

// baby.records.v1.YYYY-MM
{
  'YYYY-MM-DD': {
    milk: [{ id, time: 'YYYY-MM-DD HH:mm', type: '母乳' | '配方奶' | '混合', amount: number | null }],
    sleep: [{ id, start: 'YYYY-MM-DD HH:mm', end: 'YYYY-MM-DD HH:mm' }],
    diaper: [{ id, time: 'YYYY-MM-DD HH:mm', type: '大便' | '小便' | '都有', color: '正常' | '绿色' | '黑色' | '白色' | '带血' }]
  }
}

// baby.growth.v1
[{ id, date: 'YYYY-MM-DD', height: number, weight: number, createdAt }]

// baby.vaccines.v1
[{ id, name, month: number | null, type: '一类' | '二类', done: boolean, date: 'YYYY-MM-DD' | '', builtin: boolean }]

// baby.milestones.v1
[{ id, date: 'YYYY-MM-DD', title, note, createdAt }]

// baby.moods.v1
{ 'YYYY-MM-DD': 'happy' | 'calm' | 'fussy' | 'sleepy' | 'excited' }

// baby.notes.v1
[{ id, date: 'YYYY-MM-DD', content, createdAt }]
```

### 5.3 规则

- 所有日期与时间使用本地时间字符串，禁止使用 `toISOString()` 取日期。提供 `todayKey()`、`formatDateTime()`、`monthKey()` 等纯函数。
- id 使用「时间戳 + 随机后缀」生成。
- 读取时做结构校验，损坏数据回退为空并提示一次；写入失败弹出「保存失败」。
- `schemaVersion` 用于后续迁移；本期只读校验，不做迁移。
- 清空数据只删除 `baby.*`，不删除 `tools.*`。

## 6. 导出与恢复

导出载荷：

```js
{
  app: 'toolbox-baby',
  schemaVersion: 1,
  exportedAt: 'YYYY-MM-DD HH:mm',
  data: {
    profile, records: { 'YYYY-MM': {...} },
    growth, vaccines, milestones, moods, notes
  }
}
```

- 微信小程序：写入 `wx.env.USER_DATA_PATH/baby-record-YYYYMMDD-HHmm.json`，通过 `wx.shareFileMessage` 分享到聊天；失败时提示改用剪贴板。
- H5：复制 JSON 到剪贴板。
- 恢复：
  - 微信小程序使用 `wx.chooseMessageFile` 选择 JSON 文件；H5 粘贴 JSON。
  - 校验 `app`、`schemaVersion`、字段结构；校验失败不写入。
  - 写入前把当前 `baby.*` 快照保存到 `baby.backup.v1`，然后覆盖。
  - 恢复成功后提示并刷新页面数据。
- 导入文件限制 2MB；基础库不支持 `shareFileMessage` / `chooseMessageFile` 时，导出与恢复降级为剪贴板 JSON。
- 清空数据删除全部 `baby.*`（含 `baby.backup.v1`），确认文案明确提示「记录和备份都会删除且不可恢复」。

## 9. 技术方案

- uni-app Vue 3 + Vite，沿用现有条件编译。
- `pages.json` 增加 `subPackages`：root 为 `package-baby`，五个子页面。
- 主包保留工具页、宝宝首页、关于页；宝宝子页面全部在分包。
- 纯逻辑抽到 `src/utils/baby/`：
  - `date.js`：本地日期、月龄、格式化。
  - `records.js`：日常记录增删、今日统计。
  - `growth.js`：生长记录增改与图表数据。
  - `vaccines.js`：参考清单初始化、状态计算。
  - `backup.js`：导出载荷构建、导入校验、备份。
- 常量放 `src/data/`：`vaccinePlan.js`、`referenceMilestones.js`。
- 组件放 `src/components/baby/`：`LineChart.vue`、`Disclaimer.vue`。
- 不引入图表库，避免主包/分包体积膨胀。

## 10. 异常处理

- 存储读取异常：回退默认值，页面继续渲染。
- 存储写入失败：`uni.showToast` 提示「保存失败」，不更新页面状态。
- 表单非法：行内错误提示，不写入。
- 图表无数据：显示空状态，不绘制坐标轴。
- 资料缺失：首页显示设置引导，不计算月龄。
- 导入失败：提示具体原因（格式错误 / 版本不支持 / 字段缺失），不改动现有数据。
- 导出失败：提示剪贴板备选方案。

## 13. 风险与对策

| 风险 | 对策 |
|---|---|
| 健康内容审核 | 只做记录与参考；不预置药物/剂量；二类疫苗标注「自费自愿」；免责声明；按工具类申报 |
| 隐私合规 | MVP 纯本地；不申请定位；导出由用户主动发起 |
| 数据丢失 | 设置页提示；提供导出/恢复；导入前备份 |
| 主包体积 | 宝宝子页面放分包；不引入图表库 |
| canvas 兼容性 | 只实现基础折线图；真机回归 iOS/Android |
| 疫苗数据准确性 | 标注来源与日期；用户可编辑；以接种门诊为准 |
| 待办移除引发数据误解 | 不自动删除 `tools.todos.v1`；README 说明 |

## 14. 已定决策

1. 小程序改为两个 tab：工具、宝宝；待办移除。
2. 宝宝模块是记录工具，不提供医疗建议。
3. MVP 范围按第 4 节执行；其余功能二期。
4. 宝宝首页在主包，子页面在 `package-baby` 分包。
5. 数据只保存在本机，不申请定位，不做云同步。
6. 宝宝模块内广告只放宝宝首页与日常记录页，工具页保留现有广告位。
7. 视觉采用原网页粉色主题，全局生效（工具页同步换色）。
8. 旧待办本地数据不自动删除。
9. 疫苗参考预置一类和二类；二类标注「自费自愿」，不构成推荐。
